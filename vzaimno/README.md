# Взаимно — фронтенд сайта знакомств

Демо-верстка мобильного веб-приложения для знакомств в духе популярных российских
сервисов (Mamba, Twinby, Badoo): вход по номеру телефона, анкета, лента свайпов,
симпатии, переписка и профиль. Дизайн построен вокруг логотипа: две карточки
цвета слоновой кости, чёрная графика и красное сердце.

## Запуск

Сборка не нужна — только статические файлы:

```
open index.html
# либо любой статический сервер
npx http-server .
```

## Что реализовано

| Раздел | Функции |
|---|---|
| Вход | ввод и маска номера, SMS-код из 4 ячеек (демо-код `1234`), таймер повторной отправки |
| Анкета | 4 шага: имя и возраст, пол и кого ищете, цель знакомства, город и интересы, прогресс-бар |
| Поиск | колода карточек, свайп мышью и пальцем, штампы «нравится / нет / супер», кнопки действий, стрелки клавиатуры, галерея фото внутри карточки, подробная анкета |
| Фильтры | пол, диапазон возраста, расстояние, цель знакомства, только онлайн |
| Симпатии | «вы понравились» с размытием под подписку, взаимные пары, ответ взаимностью |
| Сообщения | список диалогов с поиском, новые пары строкой сверху, переписка, автоответы собеседника, индикатор набора, подсказки для первого сообщения, меню пары |
| Профиль | статистика, заполненность анкеты, фото (до 6), редактирование, верификация, уведомления, приватность, тёмная тема, выход и удаление аккаунта |
| Прочее | подписка «Взаимно+», экран взаимной симпатии, счётчики на вкладках, тосты, шторки, сохранение состояния в `localStorage` |

## Структура

```
vzaimno/
├── index.html          каркас экранов
├── assets/
│   ├── logo.svg        логотип
│   └── mark.svg        знак для шапки и favicon
├── css/
│   ├── base.css        токены, темы, каркас устройства
│   ├── components.css  кнопки, поля, чипы, списки, шторки
│   └── screens.css     экраны: вход, анкета, лента, чаты, профиль
└── js/
    ├── icons.js        набор inline-SVG иконок
    ├── avatar.js       генератор портретов анкет (SVG в data-URI)
    ├── data.js         демо-анкеты, города, интересы, цели
    ├── store.js        состояние и localStorage
    ├── ui.js           тосты, шторки, форматирование
    ├── auth.js         вход и пошаговая анкета
    ├── feed.js         колода карточек, свайпы, фильтры
    ├── likes.js        симпатии и взаимные пары
    ├── chats.js        диалоги и переписка
    ├── profile.js      профиль и настройки
    └── app.js          вкладки, шапка, запуск
```

Данные пользователя хранятся только в браузере, сервер не используется.
Фотографии анкет генерируются как SVG — внешних запросов нет.

## Управление в ленте

- перетаскивание карточки: вправо — «нравится», влево — «нет», вверх — «суперсимпатия»;
- стрелки `←`, `→`, `↑` — то же с клавиатуры;
- тап по левой или правой части фото — переключение снимков;
- `Esc` — закрыть шторку, экран пары или выйти из переписки.
